# Agent instructions (Sherwood)

Read `plans/agents/PREAMBLE.md` and your lane brief. You are not a tax adviser.

## Git commit messages

**Before you run `git commit`:** write a message about the change only.

MUST NOT appear in the subject, body, or trailers:

- Provider or product names (Claude, Cursor, Codex, GPT, Anthropic, OpenAI, Copilot, Gemini, …)
- `Co-authored-by:` / `Co-Authored-By:` lines for any of the above
- `Claude-Session:`, “generated by”, “generated with”, “Made-with:”

If your tool appends a trailer, strip it. If `git commit` is rejected by `.githooks/commit-msg`, fix the message and retry. Do not use `--no-verify`.

`.githooks/commit-msg` is the enforcement. Enable it with `git config core.hooksPath .githooks` (or `pnpm install`, which runs `prepare`).
