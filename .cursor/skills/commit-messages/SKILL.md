# Commit messages

Subject and body describe the change. Nothing else.

Forbidden in the entire message (including trailers):

- Claude, Cursor, Codex, GPT, Anthropic, OpenAI, Copilot, Gemini
- `Co-authored-by:` / `Co-Authored-By:` naming those
- `Claude-Session:`
- “generated by”, “generated with”, “Made-with:”

The repo hook `.githooks/commit-msg` rejects violations. Do not use `--no-verify`. Fix the message and commit again.
